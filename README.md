# Math Tutor

Math tutor manager for LLM-driven learning.

## Motivation

LLMs are good at teaching individual math concepts. They are, however, not capable of tracking long term progress. I wanted a stable curriculum to work through methodically across many LLM agent sessions and devices.

## What Is It?

MathTutor provides a curriculum graph for concepts that build on each other. Each concept has a short lesson and and quizzes. It schedules quizzes with Anki-style spaced reptition via [FSRS](https://github.com/open-spaced-repetition/fsrs4anki). Lesson and quiz content is lazily generated by the LLM at runtime. The LLM also grades quizzes. Once the LLM generates content, it is saved forever and any returns to a lesson/quiz are deterministic.

Software handles CLI, MCP, scheduling, local data storage, and data sync. The DB is libSQL so you can get a MCP server running on Fly + a Turso backend for around $2/month.

## Is It Ready For Prod?

It works for me on my devices. I have the MCP server working inside Claude and the CLI working inside Antigravity. Both services have rough edges but they work ~90% of the time (one nine of reliability!). No data on how well it works with the ChatGPT app.

## CLI surface

Subcommands are resource-first (`mt <noun> <verb>`) and track the MCP
tool surface 1:1.

```
mt path list                       # list every path with goal / progress
mt path new <GOAL> --atom <ID>...  # start a new learning path
mt path state [--path P]           # one-screen status summary
mt path next  [--path P]           # next scheduled action (AYML on stdout)
mt path tree  [--path P]           # full reachable-graph progress view

mt graph list [<ID>] [--path P]    # browse areas / cluster children
mt graph show  <ID>  [--path P]    # detail on an atom, cluster, or area
mt graph check                     # validate the shipped curriculum
mt graph dump                      # print the user overlay AYML

mt lesson upsert <ATOM>    --body TEXT
mt quiz create <ATOM>    --difficulty D --question TEXT --answer TEXT \
                         [--rubric TEXT] [--type {free_text,multiple_choice}]
mt quiz update <QUIZ_ID> [--question TEXT] [--answer TEXT] [--rubric TEXT] \
                         [--difficulty D] [--type T]
mt quiz delete <QUIZ_ID>
mt quiz answer <QUIZ_ID> --rating {again,hard,good,easy} [--user-answer TEXT]

mt instruct                        # print the agent operator playbook
mt mcp                             # run the MCP server (SSE over HTTP)
```

See `docs/design.md` for the full design and `mt instruct` for the
embedded agent playbook.
